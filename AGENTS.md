# For coding agents

This repository is the `resume-auto-tailor` skill. Read `SKILL.md` for resume work. On installation/setup or first use, follow `references/onboarding.md` immediately if the user's workspace is not ready: help them import their own master and choose preferences before tailoring. The bundled placeholders are not candidate evidence.

For development of the skill itself, do not start candidate onboarding. Keep shared assets anonymous; private user files and outputs belong outside the distributed package. Run the regression tests after checker changes. Preserve provenance, job-fit, read-only review, layout, PDF, and visual-verification capabilities when modifying the workflow.
